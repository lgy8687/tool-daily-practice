# 日课 · 读诵与日常

一个手机优先的个人日课工具，适合在一台手机上阅读、背诵和做每日记录。

## 功能

- 《道德经》八十一章：逐章阅读、章节导航、简明白话导读、每日阅读标记。
- 《心经》玄奘译本：全文阅读，注释默认折叠。
- 独立背诵页：先选择《道德经》或《心经》，进入完整经文页面；底部按钮每点一次计数一次。
- 英语电影 100 遍计划：记录每次完整观看，设置电影名称和目标遍数。
- 每日工作记录：记录事项和耗时，按日回看，并统计近七天。
- 本地保存、JSON 导出/导入；可添加到手机主屏幕，缓存后离线使用。

## 数据与隐私

所有打卡数据仅保存在当前设备、当前浏览器的本地存储中。GitHub Pages 只提供网页文件，不会收到或保存个人打卡记录。清理浏览器网站数据前，请先在“设置”中导出备份。此版本不提供跨设备同步。

## 《道德经》文本

《道德经》原文依据维基文库收录的[王弼本](https://zh.wikisource.org/zh-hans/道德经_(王弼本))，从繁体转换为简体；章名和白话导读为本工具整理，仅供个人阅读参考。各版本可能存在异文。

《心经》采用维基文库收录的[玄奘译本](https://zh.wikisource.org/zh-hans/般若波罗蜜多心经_(玄奘))，导读为本工具整理。经文断句、个别用字可能因版本不同而略有差异。
