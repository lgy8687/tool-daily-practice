# 日课 · 读诵与日常

一个手机优先的个人日课工具，适合在一台手机上阅读、背诵和做每日记录。

## 功能

- 《道德经》八十一章：逐章阅读、章节导航、简明白话导读、每日阅读标记，生僻字与多音字可开启拼音标注。
- 《心经》玄奘译本：全文阅读，注释默认折叠。
- 独立背诵页：先选择《道德经》或《心经》，进入完整经文页面；底部按钮每点一次计数一次。
- 手动开始计时，切到后台继续，返回首页时结束并记录。
- 原文和译文可自行编辑排版，自动保存在本机。
- 统计页选择日期后，可直接修改背诵次数和计时时长。
- 本地保存、JSON 导出/导入；可添加到手机主屏幕，缓存后离线使用。

## 数据与隐私

所有打卡数据仅保存在当前设备、当前浏览器的本地存储中。GitHub Pages 只提供网页文件，不会收到或保存个人打卡记录。清理浏览器网站数据前，请先在“设置”中导出备份。此版本不提供跨设备同步。

## 《道德经》文本

《道德经》原文依据维基文库收录的[王弼本](https://zh.wikisource.org/zh-hans/道德经_(王弼本))，从繁体转换为简体；章名和白话导读为本工具整理，仅供个人阅读参考。各版本可能存在异文。

《心经》采用维基文库收录的[玄奘译本](https://zh.wikisource.org/zh-hans/般若波罗蜜多心经_(玄奘))，导读为本工具整理。经文断句、个别用字可能因版本不同而略有差异。

按方案 2 做了全套视觉重做，覆盖首页、统计、阅读、背诵、我的全部页面：

- [DESIGN.md](DESIGN.md)：色彩 / 字号 / 间距 / 圆角 / 组件的唯一规范。
- [design/preview.html](design/preview.html) 与 [preview.png](design/preview.png)：高保真设计稿（首页 + 统计页 + 规范板），也是同步到 Pixso 的源文件。
- 首页：今日修习为唯一主卡（大数字 + 连续天数朱砂徽章 + 一键记一遍），两课保持两张独立大卡（≥140px），补近七日趋势。
- 统计页：连续天数为主角、12 周分级热力格、近 7 日趋势、编辑区收进热力卡内默认折叠。
- v4.1：恢复大卡片观感（首页两课 + 选择背诵页）。
- **v4.2 三处调整**：
  - 底部导航压到 **54px**，Unicode 符号换成统一线性 SVG，激活态只用朱砂细指示条；内容底部留白同步收紧到 64px。
  - 诵读计数**去掉两个木鱼**，改成「整块主点击区 + 轻量撤销」。依据成熟计数器产品的不对称原则：TapTap++ 把下半屏做成一整块点击区并配触感反馈、数字念珠（Digital Mala）主张「计数毫不费力、撤销容易、重置难」、1Button +1 按单手拇指可达性区分主次任务。点按保留涟漪、＋1 浮字、数字弹跳与触感反馈。
  - 《道德经》生僻字与多音字加 `<ruby>` 拼音。读音表在 [data/dao-pinyin.js](data/dao-pinyin.js)（约 100 个单字 + 37 条语境词条），背诵页与阅读页共用，「拼」按钮可开关并记忆；排版编辑保存时自动剥离 `<rt>`，不会把拼音写进原文数据。**只标确定读音**，注本有分歧的（多言数穷之「数」、见素抱朴之「见」等）一律不标。
- 全站只保留墨绿 `#2F5D50` 与唯一强调色朱砂 `#C0533B`；无阴影、无渐变。

改样式时请先看 DESIGN.md；`styles.css` 末尾的「v4 / v4.1 / v4.2 视觉覆盖层」是最终覆盖层，视觉改动写在这里，不要往历史层追加。改完必须同步 bump `index.html` 的 `?v=` 与 `service-worker.js` 的版本号，否则离线缓存不会更新。
